# 调试信号规划

- 先写清要分辨的两种结果，挑最少的信号。优先用已有日志或无侵入观测；只有现有通道不够且获准修改时才插桩。
- 为信号标注来源和层级、单位、字节序或事件含义、时间基准、触发、采样频率或事件频率、持续时间和判据。记录板卡、目标、固件版本和通信设置；无法确认的字段保留未知。
- 预算带宽、缓冲和 CPU 影响。事件间隔不稳定时记录序号、设备时钟和丢样计数。高速 ISR 优先计数或写入有界缓冲，避免为观察引入阻塞打印。主机收取时间包含传输和调度延迟；需要边沿、总线时序或 ISR 间隔时，使用对应仪器或设备端时间戳。
- 区分数据缺失和正常零值。先保留原始字节或原始仪器记录，再解码；拆帧、缺帧、截断和时间基准变化要可见。停止条件按任务写清，避免无限采集。
- 可用 `firmware-build-flash-runner` 的串口接收或离线回放。对 CAN、SWD、逻辑分析仪，使用已确认的项目工具；不要将其当作该运行器已内置的后端。
