# 嵌入式官方资料获取

1. 先确认要回答的问题、准确型号、封装或板卡版本、SDK 或内核版本及所缺资料。已提供本地资料时先用现有资料，核对版本和适用范围。
2. 缺资料时按任务寻找厂商产品页、文档库、官方 SDK 仓库或项目维护者的版本化文档。搜索结果只是线索；打开官方入口确认文档号、版本、适用器件和实际链接。镜像、论坛、经销商及同系列其他器件不能直接替代。
3. 仅查找时报告来源、匹配依据、已知冲突和缺项。用户要求下载或归档时才写到约定位置。已核对的公开 HTTPS 直链可用 [参考资料归档工具](references/archive.md) 保存；工具不能代替对发布者、版本和适用范围的核对。
4. 保留原始字节和来源记录；摘录另存。以实际生成的文件和校验值为准。登录、协议确认、网络失败、链接不可用或版本不明时说明缺什么，不把错误页或同系列资料当作结果。需要开档或解压时作为单独动作；不运行下载物。
5. 交给下游时提供文档类型、文档号或发布标签、适用型号、官方入口、记录或路径、SHA-256 及精确定位。资料提取交给 `mcu-datasheet-extractor` 或项目对应的分析技能。
