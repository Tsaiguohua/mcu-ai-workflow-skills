# 芯片手册提取

目标不是概括整本手册，而是按当前任务提取能直接指导硬件接线、固件实现和调试验证的事实。不要让 AI 通读手册后写读后感，要让它围绕一个任务抽证据。

## 输入

- 芯片/模块厂商、型号、封装。
- 数据手册、参考手册、勘误、应用笔记、SDK 文档。
- 当前任务：例如 UART 通信、I2C EEPROM、SPI Flash、PWM 输出、ADC 采样、低功耗、功放芯片接线。
- 已知板级约束：晶振、电压、引脚、接口、负载、开发板资源、软件框架。

如果缺少手册，且问题涉及版本差异或芯片细节，先要求用户提供或查官方资料，不要凭记忆下结论。

## 工作流

1. 确认文档身份  
   记录标题、版本、日期、适用芯片/封装、文件路径或来源链接。区分 datasheet、reference manual、errata、application note 和开发板教程。

2. 判断任务类型  
   不同任务提取不同内容。先识别是引脚接线、外设初始化、时序参数、电气极限、寄存器配置、低功耗、通信协议还是异常排查。

3. 锁定相关章节  
   只读取与任务相关章节：pinout、alternate function、electrical characteristics、timing、registers、application circuit、layout、power、reset、errata。

4. 提取可执行事实  
   包括引脚定义、推荐接法、复用功能、时钟/复位、中断/DMA、寄存器位域、时序、电气极限、默认值、初始化顺序、限制条件、勘误。

5. 标注证据来源  
   关键事实必须带页码、章节、表号或图号；证据不足写 `待确认`；区分手册事实和工程推断。

6. 输出任务导向文档  
   用后续固件开发能直接引用的形式输出，不做泛泛总结。

## 按任务提取模板

### I2C / EEPROM / 传感器时序

提取内容：

- 器件地址、地址脚配置、读写命令格式。
- `tLOW`、`tHIGH`、`tSU.DAT`、`tHD.DAT`、`tSU.STA`、`tHD.STA`、`tSU.STO`、`tBUF`、`tAA`、`tR`、`tF` 等时序。
- ACK/NACK、页写大小、写周期、忙等待方式。
- 上拉电阻、总线电容、供电电压、输入阈值。
- 硬件 I2C 与 GPIO 模拟 I2C 对软件延时的影响。

输出重点：给出软件 I2C 延时建议、硬件 I2C 速率建议、页写和 ACK polling 注意事项。

### SPI Flash / SPI 外设

提取内容：

- 支持的 SPI 模式：CPOL/CPHA、最大时钟、单线/双线/四线。
- 指令表：读 ID、读数据、页编程、写使能、扇区擦除、块擦除、读状态寄存器。
- 页大小、扇区大小、块大小、容量、地址宽度。
- 写擦时间、擦写寿命、数据保持时间。
- `CS` 默认态、`WP/HOLD` 引脚建议、MISO 三态行为。

输出重点：初始化参数、读写擦流程、写前擦除策略、状态轮询、掉电保护风险。

### UART / 串口模块

提取内容：

- TX/RX 引脚方向、默认电平、电气电平：TTL/RS232/RS485。
- 波特率范围、帧格式、流控、唤醒/睡眠脚。
- 复位脚、启动脚、状态脚、AT 指令或协议入口。
- 模块上电时序、启动等待时间、异常复位方式。

输出重点：接线方向、初始化波特率、上电初始化顺序、串口调试和日志保留建议。

### PWM / 定时器 / 电机 / 蜂鸣器

提取内容：

- 可用定时器通道、复用引脚、频率范围、分辨率。
- 输出极性、互补输出、死区、刹车输入。
- 上电默认态、使能顺序、危险输出限制。
- 负载驱动器输入阈值和保护要求。

输出重点：推荐定时器/通道、频率/占空比约束、安全默认态和最小验证步骤。

### ADC / 模拟采样

提取内容：

- ADC 通道和引脚、分辨率、采样时间、转换时间。
- VREF/VDDA 范围、输入电压范围、输入阻抗建议。
- 内部温度/Vrefint/电池通道。
- 采样源阻抗、滤波电容、过压保护、校准要求。

输出重点：通道表、采样时间建议、分压/滤波/保护建议、软件滤波和校准注意事项。

### 低功耗 / 睡眠 / 唤醒

提取内容：

- Sleep/Stop/Standby 等模式差异。
- 保持的 RAM/寄存器/外设。
- 唤醒源、唤醒延迟、时钟恢复。
- IO 保持状态、漏电路径、调试口影响。
- 进入/退出流程和勘误。

输出重点：模式选择建议、唤醒源配置、进入前外设处理、退出后重初始化清单。

### 电气参数 / 绝对最大额定值

提取内容：

- 供电范围、IO 输入输出电压、驱动能力、输入阈值。
- 温度范围、ESD、上电时序、复位阈值。
- 功耗、电流峰值、负载能力。
- 绝对最大额定值和推荐工作条件的区别。

输出重点：不可越界项、硬件设计边界、需要人工确认的风险。

### 引脚定义与接线建议

适用于功放、传感器、电源芯片、通信模块、显示屏、存储芯片等外设。

提取内容：

- 封装顶视图、引脚编号方向、每个引脚功能。
- 推荐典型应用电路。
- 必需外围器件：上拉、下拉、去耦、耦合、电阻、电容、晶振、匹配网络。
- 控制脚有效电平：EN、RESET、CS、SHDN、PWDN、INT。
- 布局建议：去耦位置、模拟/数字地、走线长度、差分线、敏感输入。

输出重点：接线表、MCU 控制建议、默认态建议、不要悬空的引脚、布局注意事项。

## 质量要求

- 不要编造寄存器名、位号、复用功能、复位值、时序数值或典型电路。
- 不要把不同芯片型号、不同封装、不同速度等级的信息混在一起。
- 不要把开发板教程当作官方芯片电气参数来源；关键电气和寄存器事实应回到官方手册。
- 解释时序图时，要说明该参数对软件延时、采样点或初始化顺序的影响。
- 如果 PDF/OCR 质量差，要明确说明并要求更高清资料。
- 输出要服务当前任务，不要做大而全摘要。

## 常见坑

- 把家族参考手册当成某个封装的引脚证明。
- 漏掉会影响外设行为的勘误。
- 只提寄存器，漏掉时钟/复位使能顺序。
- 只提引脚，不提默认态和有效电平。
- 混淆绝对最大额定值和推荐工作条件。
- 摘录太宽泛，后续写代码时仍然没有精确位域、时序或接线依据。
